# Material visual de referência

Esta pasta contém cópias byte a byte das imagens encontradas na raiz do workspace em 20/08/2026.

Os arquivos são material conceitual, não spritesheets de produção: têm alta resolução, fundo RGB incorporado e quadros de tamanhos irregulares. Eles foram preservados sem recorte, remoção de fundo, redimensionamento ou sobrescrita. O graybox usa formas vetoriais temporárias desenhadas pelo Godot.

Antes de transformar qualquer folha em arte jogável, é necessário definir grade, pivôs, hitboxes, transparência e direitos de uso de cada fonte.
